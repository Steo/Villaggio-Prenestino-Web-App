Plugin WordPress ufficiale per la Web App del Comitato di Quartiere Villaggio Prenestino.
Novità v1.3.1: Menu WordPress unificato e ordinato sotto un'unica voce "🏡 VP Quartiere" con navigazione a schede (Tab) per gestire eventi con anno completo, richieste di volontariato con raccolta recapiti telefonici protetti, segnalazioni dei cittadini, proposte e dashboard Insight delle statistiche civiche.

== Installazione ==
1. Da WordPress vai su Plugin > Aggiungi nuovo > Carica plugin.
2. Seleziona il file zip "vp-quartiere.zip" e clicca "Installa adesso".
3. Clicca "Attiva plugin".
4. Troverai una sola voce pulita e ordinata nel menu principale di WordPress: "🏡 VP Quartiere", con tutte le sezioni raggruppate e navigabili anche tramite comode schede (Tab) interne!
5. In "VP Quartiere > Impostazioni API" trovi la chiave di sicurezza e lo stato degli endpoint REST.
